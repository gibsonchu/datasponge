# Draft governance and versioning

Floodline is the founding steward of DataSponge. This repository establishes an initial working process, not a claim that an independent foundation, formal voting membership, or elected board already exists.

Proposals are discussed in public issues; changes are reviewed through pull requests. Keep use cases, disagreements, alternatives, and migration effects visible. Recruit representatives from community organizations, government, research, and implementers as participation grows.

FRS, FMS, and FSS have independent version identifiers and share core conventions. Their initial version is `0.1.0`. Breaking changes can occur during the 0.x phase but must be documented in the changelog with migration guidance. Keep released tags immutable; do not silently revise schemas under an existing release tag.

A future 1.0 release requires representative partner implementations, reviewed field definitions, a defined conformance profile, migration guidance, and agreement on stewardship. Until then, say “validates against draft FMS 0.1.0,” not “certified FMS compliant.”

Software, specifications, metadata, and media have separate rights. Public access does not imply permission to redistribute third-party content. Hosted-catalog moderation and membership rules do not restrict independent implementation of the open specifications.
